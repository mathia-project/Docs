**Clasificación desbalanceada para el diagnóstico de diferencias cognitivas y de aprendizaje en la enseñanza de las matemáticas:**Este proyecto contiene los siguientes ficheros:**1. data\_transformation\_MathIA.ipynb**Jupyter Notebook en Python para transformación de los datos. Detalles dentro del notebook.**2. data\_transformation\_MathIA.html**Igual que 1. pero en formato HTML.**3. raw\_data.csv**Datos en crudo del proyecto.**4. transformed\_data.csv**Fichero de datos transformados (generado con el programa data-transformation-MathIA.ipynb). Usa este fichero de datos para entrenar un modelo de clasificación multiclase con las siguientes 9 clases:D0 (No diagnosis)D1 (ACNEAE - Dyslexia and Dyscalculia)D2 (ACNEAE - Attention-Decit/Hyperactivity Disorder)D3 (ACNEAE - Borderline cognitive performance)D4 (ACNEAE - Language disadvantage)D5 (ACNEAE - Dyslexia)D6 (ACNEE - Autism Spectrum Disorder)D7 (ACNEE - Borderline cognitive performance)D8 (ACNEE - High intellectual ability)**5. transformed\_data\_Binary.csv**Fichero de datos transformados con solo dos clases.  Usa este fichero de datos para entrenar un modelo de clasificación binario con las siguientes dos clases:D0 (No diagnosis)D1 (Some diagnosis)Este fichero se ha generado "a mano" modificando con Excel el fichero transformed\_data.csv para sustituir las clases D1 a D8 por la clase D1 (Some diagnosis).**6. transformed\_data\_SomeDiagnosis.csv**Fichero de datos transformados que contiene solo estudiantes con algún diagnóstico. Usa este fichero de datos para entrenar un modelo de clasificación multiclase con las siguientes 8 clases:D1 (ACNEAE - Dyslexia and Dyscalculia)D2 (ACNEAE - Attention-Decit/Hyperactivity Disorder)D3 (ACNEAE - Borderline cognitive performance)D4 (ACNEAE - Language disadvantage)D5 (ACNEAE - Dyslexia)D6 (ACNEE - Autism Spectrum Disorder)D7 (ACNEE - Borderline cognitive performance)D8 (ACNEE - High intellectual ability)Este fichero se generado "a mano" modificando con Excel el fichero transformed\_data.csv para eliminar las muestras con clases D0 (No diagnosis).**NOTA:** Con los datos actuales, se recomienda usar **transformed\_data\_Binary.csv**, los otros dos conjuntos de datos producen modelos de baja precisión debido al bajo número de muestras de entrenamiento en algunas clases en el total del dataset.**7. training.ipynb**Jupyter Notebook en Python para entrenamiento un modelo de clasificación de estudiantes, simulando una **puesta en producción**. Detalles dentro del notebook.**8. training.html**Igual que 7. pero en formato HTML.**9. modelo.pkl**Fichero serializado con el modelo de clasificación entrenado, generado con training.ipynb.**10. label\_encoder.pkl**Fichero serializado con el codificador de etiquetas para los datos de entrenamiento, generado con training.ipynb.**11. columnas\_entrenamiento.pkl**Fichero serializado con la estructura de columnas de los datos de entrenamiento, generado con training.ipynb.**12. nuevos\_estudiantes.csv**Fichero de datos con nuevos estudiantes para su clasificación (una vez entrenado el modelo).**13. classification.ipynb**Jupyter Notebook en Python para clasificación de estudiantes, simulando una **puesta en producción**. Detalles dentro del notebook.**14. classification.html**Igual que 13. pero en formato HTML.**15. EAM2025.pdf**Artículo publicado en el EAM2025 con todos los detalles del proyecto (Imbalanced Classification for Diagnosing Learning and Cognitive Differences in Mathematics Education).**16. README.md**Fichero en formato markdown con la descripción de todos los ficheros del proyecto (este fichero).
