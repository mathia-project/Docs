**Un algoritmo genético para la asignación de recursos académicos a estudiantes**Este proyecto contiene los siguientes ficheros:**1. catalogue\_and\_student\_profile\_generation.ipynb**Jupyter Notebook en Python para generación de catálogos de recursos y perfiles de estudiante. Detalles dentro del notebook.**2. catalogue\_and\_student\_profile\_generation.html**Igual que 1. pero en formato HTML.**3. genetic\_algorithm.ipynb**Jupyter Notebook en Python que carga un catálogo de recursos y un perfil de estudiante de ficheros .csv, filtra el catálogo de recursos para asegurar compatibilidad con el perfil del estudiante (y lo guarda en fichero .csv), y ejecuta un algoritmo genético para la asignación de recursos académicos a estudiantes (1O veces en el experimento). Detalles dentro del notebook.**4. genetic\_algorithm.html**Igual que 3. pero en formato HTML.**5. catalogue.csv**Catálogo de recursos generado con el programa catalogue\_and\_student\_profile\_generation.ipynb.**6. student\_profile.csv**Perfil de estudiante generado con el programa catalogue\_and\_student\_profile\_generation.ipynb.**7. filtered\_catalogue.csv**Catálogo de recursos filtrado según el perfil de estdiante, generado con el programa genetic\_algorithm.ipynb.**8. TechnicalReport-mathIA.pdf**Informe técnico con la descripción del problema de optimización, el algoritmo genético y los experimentos realizados.**9. README.md**Fichero en formato markdown con la descripción de todos los ficheros del proyecto (este fichero).
